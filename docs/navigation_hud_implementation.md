# 国风导航 HUD 指引系统实现报告

**实现日期**：2026-06-23  
**版本**：v1.0

---

## 一、系统概述

### 核心需求
1. ✅ 屏幕右上角清代风水罗盘，实时显示玩家朝向、东西南北方位，标注五大院落
2. ✅ 屏幕顶部居中木质古风指向箭头，实时指向当前主线目标，目标在身后时箭头翻转提示回头
3. ✅ 抵达目标点后 HUD 保持显示，等待剧情触发后自动切换指向新目的地
4. ✅ HUD 布局自适应全屏窗口，不遮挡对话 UI、场景画面，色调米黄+烫金+古风统一
5. ✅ M 键可隐藏/显示导航 HUD

## 二、实现细节

### 2.1 国风导航 HUD 组件

#### A. 顶部目标箭头面板（TopTargetArrow）

**位置**：屏幕顶部居中，距上方 14px，宽 360px，高 86px  
**样式**：
- 背景：半透明浓茶色（RGB 0.33, 0.17, 0.07, 0.72）
- 边框：烫金色（RGB 0.88, 0.68, 0.22），2px 宽，圆角半径 6px
- 内边距：12px 横向，8px 纵向

**内容组件**：
- **箭头符号**（▲）：
  - 大小 48×48px
  - 颜色：烫金（RGB 0.96, 0.78, 0.28）
  - **核心特性**：`pivot_offset=(24,24)` 使得旋转基准在中心，可根据相对角度动态旋转
  - 当目标在身后（相对角度 > 120°）自动翻转（+180°） + 显示"回头"提示
  
- **目标标签**（TargetLabel）：
  - 字号 20px
  - 颜色：米黄（RGB 0.96, 0.86, 0.58）
  - 显示当前阶段 hint，例如"去潇湘馆见林黛玉"
  
- **距离标签**（DistanceLabel）：
  - 字号 14px
  - 颜色：黄金（RGB 0.91, 0.74, 0.35）
  - 格式："距目标约 XX 米"；到达时改为"已到达，触发剧情后切换下一站"
  
- **转向提示标签**（TurnLabel）：
  - 字号 16px
  - 颜色：橙金（RGB 1.0, 0.62, 0.26）
  - 内容：
    - 正前方：显示"正前方"
    - 向侧：显示"向左 XX°"或"向右 XX°"
    - 身后（abs(angle) > 120°）：显示"回头"

**朝向计算**：
```gdscript
relative_angle = _get_relative_angle_to(target)
= atan2(
    (target - player) · perpendicular_forward,
    (target - player) · forward
)
```
- 正值 = 目标在玩家右侧；箭头右旋
- 负值 = 目标在玩家左侧；箭头左旋
- abs(angle) > 120° = 目标在身后；箭头翻转（+180°）

---

#### B. 清代风水罗盘（FengshuiCompass）

**位置**：屏幕右上角，距右 18px、上 18px，208×208px  
**样式**：
- 背景：浓茶色（RGB 0.58, 0.45, 0.23, 0.68）
- 边框：烫金色，2px 宽，圆角半径 108px（接近圆形）

**内容组件**：
- **方位标签**（北、东、南、西）：
  - 北：最大号（22px），金色，视觉强调
  - 东、南、西：稍小（18px），米黄
  - 位置：正北下方 8px；正东右边 172px；正南下方 174px；正西左边 12px
  
- **方位针**（◆）：
  - 大小：34px 黄金色五角星
  - 中心位置 (104, 104)
  - **核心特性**：`pivot_offset=(20,20)` 使得旋转基准在图标中心
  - 方向跟随玩家朝向（基于 `player.global_transform.basis.z`）
  
- **朝向标签**（HeadingLabel）：
  - 格式："朝向 X"，X ∈ {北, 东北, 东, 东南, 南, 西南, 西, 西北}
  - 字号 15px，米黄色，位置下方
  
- **院落标记**（5 个）：
  - 潇湘馆、怡红院、秋爽斋、蘅芜苑、稻香村
  - 栊翠庵（可选第 6 个）
  - 每个标记是 52×18px Label，字号 11px
  - 位置：沿罗盘半径 76px 圆周均匀分布
  - 计算方法：
    ```gdscript
    place_world_pos = compass_places[i].pos
    relative_angle = atan2(
      (place - player) · perpendicular_forward,
      (place - player) · forward
    )
    marker_pos_on_compass = center + Vector2(sin(relative_angle), -cos(relative_angle)) * radius
    ```
  - 结果：院落方向始终对应罗盘上的真实方向

### 2.2 核心逻辑

#### HUD 生命周期

1. **初始化**（`_init_guide()`）
   - 调用 `_create_navigation_hud()`
   - 创建 CanvasLayer（layer=7）、Control 容器、两个 PanelContainer

2. **每帧更新**（`_process()`）
   - 调用 `_update_navigation_hud()`
   - 获取当前阶段目标位置
   - 计算玩家到目标的相对角度和距离
   - 更新箭头旋转、文本内容、罗盘方位

3. **M 键切换**（`_unhandled_input()`）
   - `KEY_M` 按下时：`navigation_hud_visible = not navigation_hud_visible`
   - 控制 `navigation_hud_layer.visible`

#### 目标切换机制

- **不依赖距离消失**：旧系统在 `ACTIVATE_DISTANCE=6m` 时清除 3D 箭头，导致廊内引导消失
- **新系统**：HUD 始终保持显示，直到 `current_stage_index >= story_stages.size()`
- **切换条件**：仅当后续剧情事件触发，改变 `GameState.conditions`，才会 `_find_current_stage()` 推进阶段
- **到达反馈**：`distance <= INTERACT_DISTANCE(2.8m)` 时，距离标签改为"已到达，触发剧情后切换下一站"

### 2.3 游廊端点装饰（改善"死胡同"体验）

每条游廊两端现加入：

#### A. 出口落脚平台
- 尺寸：`floor_width + 1.2 × length 1.9`
- 高度：0.055m（视觉平台，不与人物碰撞模型冲突）
- 材质：石料灰色
- 作用：给玩家明确的"这是出口，可以往外走"视觉提示

#### B. 金色地面导向线
- 尺寸：0.34 × 1.45（细长条）
- 高度：0.125m（紧贴地面上方）
- 材质：烫金色
- 作用：廊内看向出口时，金线在视线内指向出口，强化方向感

#### C. 出口标签（Label3D）
- 文字："出口"
- 字号：22px，烫金色
- 位置：廊端上方 1.85m，高于玩家视线
- 旋转：按廊道方向调整，避免朝向有歧义

#### D. 灯笼柱
- 位置：廊端两侧，距地面 1.35m 起 2.7m 高的圆柱
- 灯笼装饰：顶部 0.32m 高金色圆柱
- 材质：红木 + 烫金
- 作用：廊端可见的美学里程碑，告诉玩家"这里是廊的边界点"

## 四、与现有系统的融合

### 保留元素
- 3D 箭头（`arrow_nodes`）：当距离 > ACTIVATE_DISTANCE 时仍显示，距离近时清除
- 底部 HUD 提示（`hud_hint_label`）：仍保留，但新 HUD 更主要
- 阶段通知（`_show_stage_notification`）：仍弹出

### 优先级
- **主导航**：顶部箭头 + 罗盘（更可见、不被廊道遮挡）
- **辅助**：3D 箭头（远距离参考）+ 底部文字（备选）

### 层级
- NavigationGuide `layer=7`
- DialogUI 等游戏 UI `layer=8-10`
- 不会遮挡对话框

## 八、已知限制和注意事项

1. **罗盘院落标记**：仅支持 6 个固定位置，如需添加更多，需手动编辑 `compass_places` 数组
2. **HUD 透明度**：面板背景略透，在明亮背景下可能不够突出；暗夜场景中应问题不大
3. **M 键硬编码**：未通过 InputMap，避免冲突；若需自定义，改 `KEY_M` → 其他 `KEY_*` 常数
4. **相对角度计算**：使用 `player.global_transform.basis.z`，假设标准 FPS 摄像机；若自定义摄像机需调整
5. **游廊装饰**：所有游廊都会应用装饰；若某些廊段不需要，可在 `_build_corridor()` 调用时跳过 `_decorate_corridor_exits()`

1. **音效**：箭头转向或到达时播放古风提示音
2. **动画**：罗盘指针可添加微微转动，箭头到达时放大/闪烁效果
3. **自适应**：根据设置或难度可隐藏罗盘或箭头（导航难度等级）
4. **轨迹回放**：记录玩家全程轨迹，后期可展示走过的路线
5. **语音提示**：TTS 播放"向左转 30°"或"回头"的实时语音指导
